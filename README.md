# 自律神経バランスチェック

資料PDFをもとに作成した、ブラウザで使えるセルフチェックアプリです。

## 使い方

`index.html` をブラウザで開くと使えます。

質問は全部で30問です。各質問に0点から4点で回答すると、最後に以下を表示します。

- 緊張スイッチ度
- 回復スイッチ低下度
- 元気スイッチ低下度
- 4タイプ分類
- タイプ別の解説

## 判定

緊張スイッチ度と回復スイッチ低下度を使って、次の4タイプに分類します。

- A：すこやかバランスタイプ
- B：がんばりすぎ緊張タイプ
- C：休んでも回復しにくいタイプ
- D：ぐったり消耗タイプ

元気スイッチ低下度は、結果文の補足として表示します。

## 注意

このチェックは医療的な診断ではありません。強い症状や長引く不調がある場合は、医療機関への相談をおすすめします。
