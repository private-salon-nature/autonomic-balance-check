# 自律神経バランスチェック

資料PDFをもとに作成した、ブラウザで使えるセルフチェックアプリです。

## 使い方

`index.html` をブラウザで開くと使えます。

質問は全部で20問です。各質問に0点から4点で回答すると、最後に以下を表示します。

- 交感神経スコア（40点満点。高いほど良い状態）
- 副交感神経スコア（40点満点。高いほど良い状態）
- 4タイプ分類
- タイプ別の解説
- 今日から始められるセルフケア

## 判定

交感神経スコアと副交感神経スコアを使って、次の4タイプに分類します。各スコアは24点以下を偏りが出やすい目安として判定します。

- A：いきいきタイプ
- B：頑張りすぎタイプ
- C：ぼんやりタイプ
- D：ぐったりタイプ

## 注意

このチェックは医療的な診断ではありません。強い症状や長引く不調がある場合は、医療機関への相談をおすすめします。
